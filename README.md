# E-Hentai → VK: сервер

Самостоятельный Git-репозиторий только для серверного приложения. Все команды ниже выполняются из его корня — папки `server/`; файлы соседних проектов для сборки и запуска не нужны.

Сервер по [ТЗ](docs/specification.md): API, постоянные черновики, хранение изображений, очередь и адаптер публикации VK. Настроена цель `quetzalcoatl_cosplay`; для запуска публикации нужен пользовательский токен и проверка постоянного Donut/приватности вложений по [инструкции VK](docs/vk.md). До прохождения проверок принятые задачи сохраняются в очереди. Приложение не обращается к E-Hentai; файлы передаёт браузерное расширение.

Реализовано:

- API `/ehvk/api/v1` с Bearer-токеном из файла, health endpoints без пользовательских данных.
- SQLite: версионированная миграция, WAL, внешние ключи, транзакции, резервная копия перед следующими миграциями.
- Случайные страницы всех размеров галереи, наборы 4/9, замена с исключением всех текущих страниц.
- Автозаполнение и нормализация хештегов, ручное имя модели и её переключатель.
- Потоковая загрузка JPEG/PNG/WebP/GIF/AVIF, преобразование статических WebP/GIF/AVIF в PNG до предпросмотра, отказ от анимации, SHA-256 и лимиты размера, пикселей и диска.
- Версии черновиков, идемпотентное подтверждение, проверка повторной галереи в транзакции, неизменяемые снимки.
- Отложенная очередь ВК по Минску: передача сразу после подтверждения, обычный пост в слот, Donut через минуту; обход занятых минут, пауза передачи, отмена и повтор ещё не переданного остатка, история и очистка файлов.
- Адаптер VK API 5.199: фото стены, посты от имени сообщества, постоянный Donut, проверка результата, частичный успех, журнал намерений и сверка без слепого повтора.
- Docker/Compose, пример Caddy, CI и резервное копирование SQLite через backup API.

## Локальный запуск

Целевая версия — Node.js **24.21.0** (см. `.node-version`); npm. Все зависимости закреплены в `package-lock.json`.

Быстрый локальный запуск: `npm ci`, затем `npm run dev:local`. Команда создаёт отсутствующий токен в `secrets/api-token.txt`, сохраняет уже существующий и запускает приложение на `127.0.0.1:3000`. В расширении укажите `http://127.0.0.1:3000`. Домен `revoulce.ftp.sh` используется после отдельного развёртывания и настройки HTTPS.

```powershell
npm ci
New-Item -ItemType Directory -Force secrets | Out-Null
node -e "require('node:fs').writeFileSync('secrets/api-token.txt', require('node:crypto').randomBytes(32).toString('base64url'), {mode:0o600,flag:'wx'})"
$env:API_TOKEN_FILE = (Resolve-Path secrets/api-token.txt).Path
npm run dev
```

Не перезаписывайте существующий токен при каждом запуске. Для Linux команды приведены в [инструкции установки](docs/installation.md). Сервер слушает `127.0.0.1:3000`; пользовательские запросы требуют `Authorization: Bearer <токен>`. HTTP используется локально, внешний доступ — через HTTPS-прокси.

```text
npm run typecheck  # Проверка типов
npm test           # Логика и интеграционные проверки с синтетическими изображениями
npm run build      # Компиляция и копирование миграций
npm run check      # Все три проверки
npm start          # Запуск собранного сервера
npm run backup -- <путь-к-копии>  # Только при остановленном сервере
```

Тесты не используют реальные аккаунты и не публикуют записи. Их временные каталоги создаются внутри репозитория и удаляются после проверки.

## Структура

```text
src/                    API, хранилище, очередь, расписание, интерфейс публикации
src/shared/             Схемы запросов, тексты, выбор страниц
migrations/             SQL-миграции
tests/                  Unit и интеграционные проверки
deploy/                 Dockerfile, Compose, Caddy, публичная конфигурация
docs/                   Контракт API, установка, обслуживание, результаты интеграций
```

Подключение пользовательского токена, команды `vk:auth`/`vk:check` и Docker-конфигурация описаны в [docs/vk.md](docs/vk.md). Адаптер реализован и проверяется с фиктивными ответами VK; живые проверки с вашим аккаунтом и на целевом Ubuntu остаются отдельным этапом. Сервер сохраняет JPEG/PNG без изменения байтов и преобразует статические WebP/GIF/AVIF в PNG.

Встроенный `node:sqlite` в Node 24.21.0 имеет [статус Release candidate (Stability 1.2)](https://github.com/nodejs/node/blob/v24.21.0/doc/api/sqlite.md). Его использование ограничено модулем `database.ts`; версии Node и контейнера закреплены. Запускайте один экземпляр приложения на один каталог данных. Журналы идут в stdout, Docker ограничивает их объём до 50 МиБ; удаление журналов по возрасту в семь дней пока не реализовано.
